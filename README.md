# Casiran-Rien
---
Prérequis : Avoir la librairie Pygames d’installé sur son ordinateur
Pour quitter ou retourner en arrière, utiliser echap
Liser bien sur certains jeux comment continuer (3/4 du temps c'est espace ou entrée)
Si vous voulez avoir de l'argent, créer un compte et connectez-vous
Loto : Cliquer sur 5 numéros que vous voulez, et le complémentaire que de 1 jusqu'à 10
Simulateur de dé : Gagner 3 manches avant l'ordinateur ou vous perdez
Blackjack : Ne dépasser pas 21, tirer ou couché quand vous le sentez
Roulette : Miser une ou plusieurs mises sur couleur(x2) ou numéro(x36)
Bandit manchot : Ayez 3 symboles identiques
Bataille politique : Miser sur un politique et prier pour que vous ayez juste 
Chifoumi : Gagner 3 manches avant l'ordinateur ou vous perdez
Ne jouer pas avec parcimonie, jouez énormément nous sommes comme votre seconde famille (voir première !)
