## Règles des jeux :
- ### Loto :
    - Il faut sélectionner les 5 numéros que vous voulez, et le numéro complémentaire allant de 1 jusqu'à 10. Il faut minimum 2€ sur le compte pour pouvoir lancer ce jeu, sinon, il ne se passera rien.
- ### Simulateur de dé : 
    - Il faut gagner 3 manches de jets de dés contre l'ordinateur avant lui. C’est un jeu de pur hasard où vous choisissez à chaque manche le nombre de jets et le nombre de faces des dés utilisés. 
- ### Blackjack (Lite) :
    - Le joueur tire autant de cartes qu’il veut, ayant chacune une valeur mais il peux aussi se coucher, tirant une dernière carte et si celle-ci fait dépasser 21 à valeur de la main, il gagne, sinon, il perds. C’est un pur de stratégie et de hasard où il faut sentir quand il faut tirer ou quand il faut coucher. Si vous êtes exactement 21, vous gagnez trois fois votre mise.
- ### Roulette : 
    - Il faut miser une somme d’argent sur une ou plusieurs mises par couleur ou numéro. Si vous avez raison sur la couleur, vous faites un fois deux sur votre mise et si vous avez raison sur le numéro, vous faites un fois trente-six sur votre gain.
- ### Bandit manchot : 
    - Pour obtenir le jackpot, il faut obtenir trois symboles identiques sur un tirage. Il faut minimum 5€ sur le compte pour pouvoir lancer le jeu. Si vous n’avez que 2 symboles identiques, vous gagnez un plus maigre prix.
- ### Bataille politique : 
    - Il faut miser une somme sur un personnage politique présent et espérer que le bataille vous soit favorable. 
- ### Chifoumi : 
    - Il faut gagner 3 manches de chifoumi *(pierre-feuille-ciseau)* contre l’ordinateur avant lui. Les choix de l’ordinateur sont purement aléatoires.
